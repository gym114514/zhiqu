# 学习脚本 v2：按目标选择活动

## 版本兼容

- 旧版 v1 的 prediction / experiment / explanation / transfer / recall 字段仍可导入和播放。
- 新生成使用 version: 2 及 steps 数组。播放器直接按数组顺序执行，允许重复同类节点、重排或省略不必要环节；不再强制统一六步。
- 每次导入都重新开始一段体验，包括同 id 的修订稿。

## 学习策略与真实活动

| 策略 | 适合的目标 | 要求的差异化活动 |
|---|---|---|
| mechanism | 理解为何发生、条件变化有何影响 | 可选择预测、对照、思想实验、解释 |
| concept | 分清定义与适用边界 | 至少一个 classify：对正例、反例或临界例做分类 |
| procedure | 学会如何做一件事 | 至少一个 worked_example：分步示范、新任务、按需提示、自查 |
| evidence | 根据材料评估判断 | 至少一个 investigate：看材料，区分支持、反驳、信息不足，提出后续调查 |

策略描述的是学习目标，不是学科的固定标签。例如历史也可以学史料分类、研究步骤或证据推断。AI 必须写出选型理由，且脚本必须真的包含相应活动。

其他可组合节点：explain、choice、cards、reflect。步骤总数 2–8，通常 3–5。时间与活动数是可调整的产品假设。

## 缺少 correct 的处理

生成指令包含完整、可通过校验的示例及详细 JSON Schema；特别指出每个选择题选项必须有 label、correct、feedback。correct 必须为布尔值，一题恰好一个 true。

导入器一次报告所有错误的位置，不会只显示第一条。旧版的 8 个 correct 都缺失时，会完整报告 8 处，包括 prediction.options[0].correct 至 transfer.options[3].correct。

提供“复制修复指令，发回 AI”：包含原稿、全部诊断、完整选项示例及保留原版本/内容/路径的要求。程序不会猜测正确答案，不会将缺失字段一律补 false。修复后需重新导入并校验。

来源、事实及教学质量仍需核对。格式通过不等于正确，模型自检也不能保证输出永不出错。

## 测试

新增回归覆盖：双版本兼容、8 个缺项完整报告、v2缺项、无效分类引用、重复步骤id，以及“改了策略名称却缺少对应活动”的拒绝路径。三条 v2 示例分别使用分类、证据探究、逐步示范。
